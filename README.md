# CitizenWatch

CitizenWatch is a full-stack thesis project for geolocation-based infrastructure reporting.

This repository contains two separate React + Vite applications:

- `citizenwatch-citizen`: Citizen-facing PWA for creating and tracking reports.
- `citizenwatch-admin`: LGU admin dashboard for moderation, mapping, analytics, and report operations.

Both apps are structured around Firebase Auth, Firestore, Firebase Storage, Leaflet.js maps, EXIF validation through `exifr`, browser geolocation checks, and React Router DOM.

For defense and skill-test preparation, read `SYSTEM_DOCUMENTATION.md`, `CODE_WALKTHROUGH.md`, and `SYSTEM_ARCHITECTURE.md`.
